# Dataset provenance

`src/data/sites.json` is a scrape of the public directory
[tabworthy.pages.dev](https://tabworthy.pages.dev/) (506 site entries,
captured 2026-11-01). It is included unmodified in structure as the demo
corpus for the web-estate's first consumer suite.

- Site names, descriptions, and URLs belong to their respective owners; they
  are reproduced here for non-commercial framework dogfooding only.
- Do not ship this dataset in any published artifact of the estate (npm
  packages, crates, release assets). It is a local fixture for the
  `directory` app.
- Replace `sites.json` with your own corpus to use the app for real.
