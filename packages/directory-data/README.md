# @est/directory-data

DRAFT (tier k, last audit 2026-11-01)

The 506-site directory dataset (`src/data/sites.json`) and its normalized
access layer (`sites`, `categories`, `getSite`, `sitesInCategory`,
`featured`, `allTags`). Single home for the corpus; both the `directory`
pages app and the `directory-api` worker consume this package.

Dataset provenance and the do-not-publish boundary: `apps/directory/DATA.md`.
